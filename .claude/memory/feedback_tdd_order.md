Write tests before their implementations. When adding a new feature or component, create the test file first, then implement the code it exercises.

**Why:** User explicitly requested this when I was about to write implementation files before the corresponding tests.

**How to apply:** For any new feature work, always create the test file(s) first, then write the implementation. This applies to unit tests, feature tests, and middleware tests alike.
